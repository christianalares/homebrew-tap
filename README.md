# homebrew-tap

Homebrew tap for [Kommando](https://github.com/christianalares/kommando).

## Install

```bash
brew install --cask christianalares/tap/kommando
```

Or tap first, then install:

```bash
brew tap christianalares/tap
brew install --cask kommando
```

Kommando keeps itself up to date via its built-in updater, so the cask is marked
`auto_updates true`. To upgrade through Homebrew instead, run `brew upgrade --cask kommando`.
